# @yimsg/uikit

基于 `@yimsg/sdk` 的可嵌入 UIKit，提供 Shadow DOM 挂载、完整会话与通讯录视图、主题、国际化和响应式布局。

```bash
npm run build -w @yimsg/uikit
npm run test -w @yimsg/uikit
```

示例位于 [examples/](examples/)，组件采用 `Apache-2.0`。
